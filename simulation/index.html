Supermarket checkout simulation

Team project, Simulation course. Arena discrete-event model and an Excel Monte Carlo model.

The Arena model reproduces the observed checkout system: customers per day and time in system both fall inside the confidence intervals. Lines are short, so almost all of a customer's time is service.
